## One thing that confused me
- Why HTML needs both id and class when they seem to do the same thing. The 
  distinction is uniqueness. id is meant for one element only, class is 
  meant to be reused. Using an id on multiple elements technically works in 
  the browser but breaks the convention and causes problems when JS tries to 
  select "the" element by that id and finds several.
